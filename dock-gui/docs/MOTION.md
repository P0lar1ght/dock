# 动效规范

设计稿是静态的；交互要有过渡，不要生硬切换。
原则：快、轻、可打断；只动 transform / opacity。
尽量不动 width / height（改用 grid 行高或 scale）。
`prefers-reduced-motion` 时全部降为 0。

## 时长与缓动

- `--dur-fast`：120ms（悬停、按下）。
- `--dur-base`：180ms（展开、出现）。
- `--dur-slow`：240ms（面板、侧栏）。
- `--ease-out`：cubic-bezier(0.2, 0, 0, 1)。
- `--ease-in`：cubic-bezier(0.4, 0, 1, 1)（离场）。
- 离场比进场快约 1/3。

## 侧栏

- 展开 ↔ 收起：宽 248 ↔ 0，slow。
- 文字先淡出再收宽；展开时反过来。
- 树节点展开：grid-rows 0fr→1fr，base。
- 箭头旋转 0°→90°，base。
- 行悬停：背景色 fast。
- 选中行：背景色 base，不跳。
- 新会话进树：淡入 + 下移 4px。

## 会话区

- 切换会话：对话流淡入 + 上移 4px，base。
- 新条目：淡入 + 上移 6px，base。
- 流式文本：逐字不做动画，只做光标闪烁。
- 自动滚到底：smooth，用户上滚时停止跟随。
- 运行中：会话头显示脉冲点。

## 消息导航

- 横线：长度 / 颜色 fast 过渡。
- 列表：pop-in（原点在左），离开 160ms 后收起。
- 展开那条：fold（grid 行高），base。
- 跳转：逐帧滚动 280ms，缓出。

## 工具卡

- 折叠 ↔ 展开：grid 行高 + 透明度，base。
- 箭头旋转，base。
- 运行中：图标转圈；完成时交叉淡入。
- 失败：红色描边淡入，不抖动。

## 权限条

- 出现：从输入框上方滑入 8px + 淡入，base。
- 处理后：淡出 + 高度收起，fast。
- 铃铛红点：缩放 0.6→1 弹入。

## 输入框

- 聚焦：阴影加深 + 边框变色，base。
- 浮起态（rpg）：上移 2px + 阴影，base。
- 发送按钮：可用时从灰变黑，fast。
- 下拉菜单：scale 0.96→1 + 淡入，fast；
  原点对齐触发按钮。

## 面板

- 右侧那一栏（快捷面板 / 面板栈）：宽 0↔实际宽度 + 内容淡入，slow。
  - 宽度按实测像素算（`rowWidth * (1 - 侧栏比例)`），不用百分比：flex item 上的百分比宽度在 WKWebView 里会塌成内容宽。
  - 收起 / 展开由「侧边面板」按钮管：按钮在那一列顶部的标签行最右（收起时回到会话顶栏右端），两边都在窗口右上角同一坐标。
  - 标签行换页：页签高亮切换，base。
- 底部终端：高度滑出，slow。
- 新对话卡片：淡入 + 上移 8px，base。
- 预设单选：边框与底色过渡，fast。

## 启动画面

- 只在连得慢时出现：400ms 内连上就不画。
- 品牌标描线 700ms（从刀尖起笔），450ms 起填色 350ms，描线随后退掉。
- 等待中呼吸：不透明度 1 ↔ 0.55，2.4s 一周。
- 1.5s 后淡入一行「正在连接 …」（远程带连接名、带最近的错误）。
- 连上：整层淡出 + 标放大到 1.04，slow。
- 减少动态：直接显示实心标，不描线、不呼吸。

## 实现

- CSS 变量放 `src/styles.css`。
- 简单过渡用 Tailwind `transition-*`。
- 进出场（挂载 / 卸载）需要库时再引入。
