# 设计任务书：通用规则

新一轮需求写成 `docs/DESIGN-TASKS-N.md`，开头引用本文件。
做完、实现完就挪进 `docs/archive/`，并在那里的 README 补一行。
历史原文见 `docs/archive/`。

## 发给谁、画在哪

- 设计方：Grok Bot 的「UI 设计助手」，在 Wonder 画。
- 文件：Wonder「Hofmann」。
- 页：「1 · 界面」（外壳、对话、整页）、工具卡页、预设页。
- 放置：先 `get_artboards` 看占用，新开一列空白；间隔 60，不压已有画板。

## 画板

- 每个状态一个画板；label 英文，`<组件> <状态>`，如 `Question Card Multi`。
- 卡片里不放作者标签 / 画板名。
- 整窗：复制 `his`（Page - Dock Shell Light Glass）再填内容，外壳不重画。
- 设置页整窗的基准是 `reis`。
- 宽度按组件：会话区卡片 868（会话区 900，左右各 16）；侧栏 248；窄栏 52；弹出菜单 300。

## 内容

- 文案中文，用真实示例文字，不用 Lorem ipsum。
- Markdown 按渲染后的样子画（标题加粗、不写 `###`）。
- 不编 Dock 给不了的数据：需求里没列的字段不加。
- 不画动效；要动的地方用一行注释写清楚（如「出现时从下方淡入」）。

## 风格基准

- 卡片：权限条 `his.cowy`。
- 弹出层：通知菜单 `quag`。
- 对话区：对话流 `tebu`。
- 侧栏行：侧栏会话状态 `poly`。
- 色值、字号以 `src/styles.css` 的 `@theme` 为准，别换色。
- 按钮：高 26、圆角 7、11px 中粗；主按钮黑底白字，次按钮白底描边。
- 字号：正文 13、说明 12、小字 11、标题 15。
- 图标：lucide，14px，线宽 2。

## 交付

- 每个画板截图确认。
- 用 `get_element_code` 导出 jsx 到 `wonder-ui/<分组>/<Name>/`（只给 PNG 不算交付）。
- 每个目录 README 写 label 和 node id。
- 验收意见逐条编号回给设计方。
