# Dock GUI 设计任务 · 第八轮：侧边聊天（给 Grok Bot · UI 设计助手）

通用要求同 `DESIGN-TASKS.md`（取值、字号、按钮、文案用中文、不画动效只写注释）。

## 这是什么

侧边聊天 = 从当前会话「分叉」出来的一段旁问，开在右侧面板里。

- 它带着主会话到此为止的上下文（只作参考），可以连续追问。
- 只读：能读文件、搜代码、跑只读命令；会改东西的命令要用户批准。
- 主会话照常跑，不被打断；两边互不影响。
- 每个主会话最多一个侧边聊天；切到别的会话再切回来还在。
- 关掉面板就销毁，不进会话列表。
- 结论回到主线有两条路：
  1. 「带回输入框」：把某条回复引用好填进主会话输入框，只填不发。
  2. 「写进主线」：让侧聊整理一段结论（≤2000 字），用户确认后写进
     主会话的上下文；不会让主线开始新的一轮。
- 主会话里会出现一张「来自侧边聊天的笔记」卡片。

示例：主会话标题「重构登录模块」（项目 acme-web）。
侧聊问题「login.ts 里那个 retry 循环为什么要 sleep 300ms？」。

## 放置与导出

  新开一列空白，不压已有画板；间隔 60。

## 1. 面板（宽 420，高 720）

头栏标题「侧边聊天」，图标 lucide `message-square`。
标题下一行 11px 灰字：「分叉自 重构登录模块 · 只读」。

- `Side Chat Empty`：刚打开，还没问。
  - 中间：图标 + 「问点什么，不打断主线」+ 两行说明：
    「带着这个会话的上下文，只读，答案不进主线。」
    「关掉面板就结束这段旁问。」
  - 底部输入框占位「问点什么…」。
- `Side Chat Answering`：问了一句，正在答。
  - 用户气泡（示例问题）。
  - 一张只读工具卡在跑：`read_file src/auth/login.ts`。
  - 正文流式中（注释：逐字出现）。
  - 输入框右侧是停止键。
- `Side Chat Idle`：答完了，又追问了一轮，共两问两答。
  - 每条回复下方悬停出一行小操作：「带回输入框」「复制」。
  - 第二条回复画成悬停态。
  - 头栏右侧（关闭左边）多一个按钮「写进主线」（图标 `git-merge`）。
- `Side Chat Parent Waiting`：主会话在等用户批准。
  - 头栏下方一条细横幅（强调色浅底）：
    「主线在等你批准 · 去看看」，「去看看」是链接。
  - 其余同 Idle。
  - 注释：主线跑完 / 出错也用这条横幅，文案「主线已完成」「主线出错了」，
    3 秒后淡出；等批准 / 等回答的不自动消失。
- `Side Chat Permission`：侧聊自己要跑会改东西的命令。
  - 面板底部、输入框上方一条权限条（照 `his.cowy`，缩到 420）：
    「侧边聊天想运行 `npm install`」，按钮「允许」「拒绝」。
  - 注释：侧聊里没有「始终允许」。

## 2. 写进主线

- `Side Chat Handback Drafting`：点了「写进主线」。
  - 对话流底部一张卡：转圈 + 「正在整理结论…」+ 按钮「取消」。
  - 输入框禁用。
- `Side Chat Handback Preview`：结论出来了。
  - 卡片标题「写进主线的笔记」，正文是可编辑文本框（示例三行结论）。
  - 右下角字数「312 / 2000」。
  - 一行灰字：「主线在跑：下一步并入；闲着：下次对话时模型能看到。不会开始新的一轮。」
  - 按钮：主「写入主线」、次「取消」。
- `Side Chat Handback Done`：写进去了。
  - 卡片收成一行：对勾 + 「已写进主线」+ 链接「在主线查看」。
  - 注释：会话区右上角同时出一条轻提示「已写进 重构登录模块」，2 秒淡出。
- `Side Chat Handback Error`：整理失败。
  - 卡片：错误色 + 「没能整理出结论」+ 灰字原因「模型请求失败：429」+ 按钮「重试」。

## 3. 主会话里的笔记卡（宽 868，会话区）

- `Side Note Card Collapsed`：一行卡片，
  图标 `message-square` + 「来自侧边聊天的笔记」+ 灰字摘要第一行 + 右侧展开箭头。
- `Side Note Card Expanded`：展开后显示整段笔记（markdown），
  底部灰字「写入于 14:32 · 模型已看到」。
  注释：展开 / 收起高度过渡。

## 4. 入口与收尾

- `Side Chat Entry`：右侧工具面板（`ShortcutsPane`）里「侧边聊天」一项，
  当前会话已有侧聊时右侧显示一个小圆点（强调色），代替快捷键。
- `Side Chat Close Confirm`：关闭时侧聊还在跑或有未写入的预览：
  小弹层「结束这段侧边聊天？」+ 灰字「内容不会保存。」+ 按钮「结束」「取消」。
- `Side Chat Parent Closed`：主会话被关掉 / 删除了。
  面板正文换成：图标 + 「主会话已关闭，这段侧边聊天也结束了」+ 按钮「关闭面板」。
