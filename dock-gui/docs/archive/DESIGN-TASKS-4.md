## 0. 先读懂：Dock 的子代理是什么

- 主代理用 `task` 工具派活，参数：任务描述、角色、完整指令、是否后台。
- 角色来自预设，有中文显示名：
  - 编码预设：「探索」「计划」「通用」；
  - 守望预设：「岑」「观」「验」「锁」等。
- 子代理有自己的一段对话：思考、回复、工具调用，条目和主会话一样。
- 状态只有这五种，别加别的：
  - 运行中；
  - 空闲：这一轮做完了，留着，主代理还能接着给它发话；
  - 完成；
  - 失败；
  - 已取消。
- 另有一个「后台」标记：后台派的子代理不挡主代理，主代理会继续干别的。
- 主代理一步里可以同时派好几个（并行）。
- 父子之间用 `send_message` 互发消息；子代理做完会「回报」给主代理。
- 用户能对子代理做三件事：看过程、插一句话、打断 / 结束。
- 子代理的过程只在内存里：Dock 重启后，旧会话里只剩卡片，点开看不到过程。
- 不存在的东西别画：子代理没有独立模型、没有工作区 / 沙箱、没有 token 数。

## 1. 对话流里的子代理卡 `Subagent Card *`（宽 868）

外形照 `ToolCardStates` 的行：左图标 + 动词 + 详情 + 右侧小字。图标用 lucide `bot`。
行内容：「子代理」+ 角色胶囊（如「探索」）+ 任务描述。
示例描述：「找出 dock-gui 里所有用到 useDock 的地方」。

每个状态一张画板：
- `Subagent Card Running`：
  - 右侧：当前动作「正在读 src/dock/store.ts」+「· 6 次工具 · 1:24」；
  - 当前动作也可能是「思考中」「回复中」；
  - 注释：图标呼吸、用时每秒跳。
- `Subagent Card Background`：同上，角色胶囊后加灰色小标签「后台」。
- `Subagent Card Idle`：
  - 动词换成「已回报」；
  - 下面两行灰字：最后一次回报的摘要，超出省略。
- `Subagent Card Done`：「完成」+ 用时 + 工具次数，摘要同上。
- `Subagent Card Failed`：图标与动词红色，下面一行错误「模型请求失败：429 Too Many Requests」。
- `Subagent Card Cancelled`：灰色「已取消」，无摘要。
- `Subagent Card Expanded`：
  - 运行中卡展开：下面缩进列出最近 3 步（缩小版工具行：Read / Search / Bash 各一）；
  - 末行「查看完整过程 ›」（点了在右侧面板打开）。
- `Subagent Card Unavailable`：完成态 + 末行灰字「过程没有保留（Dock 重启过）」。

## 2. 并行组卡 `Subagent Group`（宽 868）

主代理一步派了 3 个时合成一张：
- 头行：「3 个子代理并行 · 2 个运行中」；
- 下面每个子代理一行：状态点 + 角色胶囊 + 描述 + 右侧当前动作 / 用时；
- 示例三行：
  - 「探索」找出所有用到 useDock 的地方 · 运行中；
  - 「探索」查 gateway 有没有投影子代理事件 · 运行中；
  - 「计划」列出接线步骤 · 已回报。
- 再画一张 `Subagent Group Done`：全部结束，头行「3 个子代理 · 完成」，默认折叠只剩头行。

## 3. 右侧子代理面板 `Subagent Panel *`

外壳照 sow 的面板（PanelChrome）：可在右侧打开，也能拖成独立窗口。宽按 sow 的面板宽。

- `Subagent Panel List`：本会话全部子代理。
  - 分组：「运行中 · 2」「空闲 · 1」「已结束 · 3」；
  - 每行：角色胶囊 + 描述 + 右侧状态 / 用时 / 工具次数；
  - 运行中的行下面一行灰字：当前动作。
- `Subagent Panel Detail`：点开一个子代理。
  - 头栏：返回 ← + 角色胶囊 + 描述 + 状态 + 用时；右侧「打断」「结束」两个次按钮。
  - 中间：子代理自己的对话流，样式照 `tebu`，三处不同：
    - 第一条是「主代理派的任务」，不是用户灰气泡：浅底卡，卡头「来自主代理」，长指令默认折到 4 行，「展开」；
    - 子代理 `send_message` 给主代理的话画成「回报给主代理」卡（右上小箭头图标）；
    - 主代理中途发来的话画成「主代理说」卡。
  - 底部：小号输入框，占位「给子代理补充一句…」，只有发送键，没有模型 / 推理 / 审批胶囊。
- `Subagent Panel Empty`：「这个会话还没有派出子代理」。
- `Subagent Panel Unavailable`：详情态，中间是空状态「过程没有保留（Dock 重启过）」，下面仍显示最后的回报摘要。
- `Subagent Panel Ended`：已结束的子代理：「打断」「结束」不显示，输入框换成一行灰字「子代理已结束」。
