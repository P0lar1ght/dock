## 2. 模型与密钥（最重要）

配置来自 `~/.dock/config.toml` 的 `[model.<id>]`。GUI 只写用户级这一份。
Dock 不内置任何模型：没配就是空的。

### 2.1 `Settings Models List`

- 头部：标题「模型与密钥」；
  - 副标题「保存在 ~/.dock/config.toml，改完新对话立即生效」；
  - 右侧：「在访达中显示」次按钮、「+ 添加模型」主按钮。
- 顶部一行「默认模型」下拉：deepseek-flash。
  - 下面灰字：「新对话用这个模型；DOCK_MODEL 环境变量会覆盖它」。
- 模型卡（照现在的卡，加操作）：
  - 名称 + id（等宽灰字）+「默认」胶囊；
  - 第二行：地址 host · 上下文 262k · 协议胶囊（responses / chat / messages）；
  - 右侧：密钥状态胶囊 + 悬停出现「编辑」「⋯」；
  - 「⋯」菜单：设为默认 / 复制一份 / 测试连接 / 删除。
- 三张示例卡用截图里的：
  - Atria-Dawn-Preview：api.atria-asi.ai，262k，三条协议，已配置密钥；
  - Atria-Dawn-Preview (intern)：discovery-api.intern-ai.org.cn，262k，messages；
  - deepseek-flash（默认）：api.deepseek.com，1M，三条协议。
- 密钥状态四种（胶囊）：
  - 已配置密钥（灰）；
  - 从环境变量 DEEPSEEK_API_KEY 读（灰）；
  - 环境变量未设置（橙）；
  - 未配置密钥（橙）。

### 2.3 `Settings Models Edit`（编辑抽屉或整页，你定）

分三节，节标题小号灰字：

- 连接：
  - 显示名（name）；
  - 模型 id（目录 id，新建时可填，编辑时只读）；
  - 描述（一行）；
  - 接口地址 api_base_url，占位 `https://api.example.com/v1`；
  - 上游模型名 api_model，占位「留空 = 用模型 id」；
  - 支持的协议：三个可勾选项 responses / chat_completions / messages，
    可拖动排序，第一条标「默认」；
  - 鉴权方式：自动（跟协议走）/ Bearer / x-api-key 三段式。
- 密钥：
  - 二选一的分段：「环境变量」/「直接填写」；
  - 环境变量：输入变量名 DEEPSEEK_API_KEY，右侧小字「已检测到 ✓」或「当前进程里没有这个变量」；
  - 直接填写：密码框 + 显示/隐藏眼睛；
    下面一行橙色提示「会以明文写进 config.toml，建议用环境变量」；
  - 「测试连接」次按钮，结果一行：
    - 成功：「连接成功 · 用时 420ms」；
    - 失败：红字「401 Unauthorized：密钥不对」。
- 能力（默认折叠，标题「高级」）：
  - 上下文窗口（数字，单位 token，占位「不填按 128k 估」）；
  - 单次输出上限（占位「不填不发」）；
  - 推理：开关；开时出现「默认强度」下拉 + 「可选档位」多选胶囊 low / medium / high / xhigh；
  - 支持图片：开关；
  - 提示缓存：开关（只在勾了 messages 时显示）；
  - 单价（USD / 百万 token）：输入 / 缓存读 / 缓存写 / 输出 四个小输入框；
    下面灰字「写了 /usage 才算得出金额，约数，不是账单」；
  - 按协议覆盖：每条勾选的协议一行可展开，三项 地址 / 鉴权 / 上游模型名，
    示例：messages → `https://api.deepseek.com/anthropic`、Bearer。
- 底部：取消 / 保存（主按钮）；新建时多一个「保存并设为默认」。
