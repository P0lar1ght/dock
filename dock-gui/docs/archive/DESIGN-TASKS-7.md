通用要求同 `DESIGN-TASKS.md`（取值、字号、按钮、文案用中文、不画动效只写注释）。

先读一遍视图契约：`/Users/polar/Desktop/AILab/dock/docs/PLUGIN-VIEWS.md`。
插件交的是一棵视图树（节点：stack / row / section / text / markdown / code /
kv / table / list / badge / progress / button / link / divider / empty）。

## 0. 节点图鉴 `Plugin View Gallery`

一张画板，宽 420（右侧面板的宽度），从上到下把每种节点画一遍，
每块左上角用 11px 灰字标节点名（`text`、`kv`…）：

- `text`：六种色调各一行（默认 / 灰 / 强调 / 成功 / 警告 / 危险），
  再加一行粗体、一行大号。
- `markdown`：一小段带标题、列表、行内代码。
- `code`：两行 shell，右上角复制按钮。
- `kv`：四行——环境 `production`、版本 `v2.4.1`、
  状态「运行中」（成功色）、上次部署「12 分钟前」。
- `table`：三列（服务 / 实例 / 状态）四行，最后一列用色调字。
- `list`：三行，每行标题 + 副标题 + 右侧胶囊；
  第二行是悬停态（可点）。
- `badge`：六种色调各一个。
- `progress`：一条 60% 带标签「上传中 3/5」，一条不确定进度（注释写「扫光」）。
- `button`：主 / 次 / 危险各一个，再画一个「执行中」（转圈 + 禁用）。
- `link`：「查看部署日志」带外链图标。
- `section`：展开态一个、折叠态一个（标题 + 右侧箭头）。
- `row`：一行里左边 badge、右边两个按钮（`align: between`）。
- `divider`。
- `empty`：图标 + 「还没有部署记录」+ 按钮「立即部署」。
- 不认识的节点：一行灰字「不支持的视图：chart」。

## 1. 插件面板（右侧面板的一种）

和画布 / 浏览器同一个右侧面板槽，头栏照 `sow-gos`：
拖手 · 图标 + 标题 … 分屏 · 新窗口 | 关闭。

- `Panel Plugin Deploy`：「部署助手」面板。
  - 顶部 `kv`（环境 / 版本 / 状态）；
  - `progress` 60%「上传中 3/5」；
  - `section`「最近部署」：`list` 三行，胶囊 成功 / 失败 / 进行中；
  - 底部 `row`：主按钮「部署」、次按钮「回滚」。
- `Panel Plugin Busy`：点了「部署」，按钮转圈禁用，其余照常。
- `Panel Plugin Closed`：插件自己关了面板——面板收起，会话区右上角
  一条轻提示「部署助手 已关闭面板」（注释：2 秒后淡出）。
- `Panel Plugin Error`：插件停了 / 画正文出错。
  卡片：图标 + 「面板暂时打不开」+ 灰字原因「插件 deploy 已停止」+
  按钮「重试」。
- `Panel Plugin Picker`：从哪打开。
  - 右侧面板槽的「+」菜单里加一组「插件面板」，列出当前登记的面板
    （图标 + 标题 + 插件名小字）；
  - 没有插件面板时这一组不出现（不用画空态）。

## 2. 工具卡的自定义渲染

照现有工具卡（`prev` 折叠 / `bunk` 展开 / `whan` 失败）。

- `Tool Plugin Collapsed`：工具 `deploy_status`，
  折叠行和别的工具一样（图标 + 名字 + 参数摘要 `env=production`）。
- `Tool Plugin Expanded`：展开区不是原始输出，而是插件给的视图：
  - `kv`（环境 / 版本 / 状态）+ `table`（服务 / 实例 / 状态）；
  - 展开区右上角一个小切换「视图 | 原始」，切到原始看 JSON 输出。
- `Tool Plugin Fallback`：插件没加载时，展开区是原始输出，
  上方一行灰字「插件 deploy 未加载，显示原始结果」。

## 3. 设置卡（设置 › 插件 › 某个插件）

照 `ose`（Settings Plugins）的外壳和列表。

- `Settings Plugins Config`：点开「部署助手」，详情里多一块「配置」，
  按 schema 生成表单：
  - 区域（下拉：cn / us，默认 cn）；
  - 访问令牌（密钥框：已设置时显示「已设置 · 留空不改」）；
  - 详细日志（开关）；
  - 超时秒数（数字，说明「10–600」）；
  - 备注（多行文本）；
  - 底部「保存」主按钮。
- `Settings Plugins Config Invalid`：超时填 5，字段下红字「最小 10」，保存禁用。
- `Settings Plugins Config Saved`：保存后按钮旁短暂「已保存」（注释：1.5 秒淡出）。

## 4. 状态项

插件可以放一个常驻小状态（短文字 + 色调），点它打开对应的插件面板。
放哪由你定，我的建议是输入框下面那一行状态区（目标条、上下文环的同一行），
画两个方案供挑：

- `Status Items Composer`：方案 A，输入框下状态行右侧，胶囊样式；
  三个示例：「部署中 60%」（强调）、「CI 通过」（成功）、「2 个告警」（警告）。
- `Status Items Header`：方案 B，会话头栏右侧，图标 + 短字。
- `Status Items Overflow`：超过 3 个时的折叠（「+2」，点开弹出列表）。
- 悬停：tooltip 写插件名 + 一句说明。

## 验收意见（第一轮）

GUI 是**按通用规则**画视图树：同一种节点在哪都长一样，
不能某张画板手工摆。下面按这个原则逐条改。

1. 卡片规则统一：只有 `section` 画成卡片（圆角 + 边框）。
   - `kv`、`progress`、`list` 等节点不套卡片；`table` 自带的边框保留。
   - `Panel Plugin Deploy` / `Busy` 里 kv、progress 外面的卡片去掉，和图鉴一致。
2. 面板底部固定按钮是条规则，写进注释：
   视图根 `stack` 的最后一个子节点若是只含 `button` 的 `row`，固定在面板底部。
3. `Busy`：执行中时同一面板的其它按钮也禁用（一个面板同时只跑一个动作）。
4. `Closed`：用真实会话区外壳（`his` / `sow-gos`），
   去掉「部署已完成，面板已收起。」这行假正文；toast 保留。
5. `Picker`：「+」菜单照真实菜单（`src/components/PanelChrome.tsx`）：
   浏览器 ⌘T、文件 ⌘P、桌面 ⌘⇧D、画布 ⌘⇧C、子代理，各带快捷键；
   下面再加「插件面板」一组。
6. 图标：契约里插件不能给图标。
   - 面板头栏、工具卡、「+」菜单、设置页统一用 lucide `Puzzle`，不要火箭。
   - 状态项图标由色调决定：success `CircleCheck`、warning `TriangleAlert`、
     danger `CircleX`、accent `Loader`（注释：转圈）；default / muted 不带图标。
7. `kv`：值紧跟标签——标签列固定宽 96，值左对齐。
   不要右对齐到最右（工具卡 720 宽时离太远）。图鉴、面板、工具卡统一。
8. `Tool Plugin Expanded`：表格画 4 行（任务里写的 4 行）。
9. 设置卡三张照 `ose` 外壳重画：
   - 完整设置导航（「插件与技能」选中）、顶部「插件 / 技能 / 密钥」标签；
   - 内容列宽同 `ose`（约 510）；
   - 入口：插件行右侧加「配置」文字按钮，点开**就地展开**在这一行下面
     （或子页带面包屑「插件与技能 › 部署助手」，二选一，说明选哪个）；
   - 每个字段下面显示 `description`（灰字）。
10. `Settings Plugins Config Invalid`：有错时「保存」禁用（灰）。
11. `Status Items Composer`：画在真实输入框那一行（`ComposerGoalContext`）：
    左边真的目标条 + 上下文环，右边状态项；tooltip 往上弹，别盖住发送按钮。
12. `Status Items Overflow`：状态项文字是插件给的，界面只能截断不能改写。
    - 最大宽 120，超出省略号：「部署中 60%」→「部署中 6…」；
    - 不要缩成「部署中」「CI」「2」；
    - 弹出列表样式照通知菜单 `quag`。
13. 图鉴补两处：`text` 加一行小号（size s）；`progress` 右侧显示百分比「60%」。
